### 🧩 C++ Modules (00–09) – 42 Project

## 📌 Overview
This repository contains my implementation of **C++ Modules 00 to 09** from the **1337 / 42 Network** curriculum.  
These modules introduce the fundamentals of **object-oriented programming in C++**, with a strong emphasis on **design principles**, **type safety**, and **standard library usage**.

This README focuses on the core concepts of **classes**, **inheritance**, **polymorphism**, **containers**, **streams**, and **type casting**.

---

## 🧱 Classes

Classes are the foundation of object-oriented programming in C++.  
Throughout the modules, classes are used to encapsulate data and behavior, ensuring clean and maintainable code.

### Concepts Covered
- Class structure and encapsulation
- Constructors and destructors
- Access specifiers (`public`, `protected`, `private`)
- Copy constructor and assignment operator
- Rule of Three
- Const correctness

---

## 🧬 Inheritance

Inheritance is used to model **is-a relationships** and promote code reuse.  
The modules demonstrate how derived classes extend and specialize base class behavior.

### Concepts Covered
- Base and derived classes
- Virtual destructors
- Method overriding
- Protected members
- Multiple inheritance (introduction)

---

## 🔁 Polymorphism

Polymorphism allows objects to be manipulated through base class interfaces while preserving derived class behavior.

### Concepts Covered
- Virtual functions
- Dynamic dispatch
- Base class pointers and references
- Abstract classes and interfaces
- Runtime polymorphism

---

## 📦 Containers

The **Standard Template Library (STL)** containers are used to manage collections of data efficiently.

### Concepts Covered
- Sequential containers (`std::vector`, `std::list`, `std::deque`)
- Associative containers (`std::map`, `std::set`)
- Iterators and iterator categories
- Algorithms and container traversal
- Performance and complexity considerations

---

## 🌊 Streams

Streams provide a safe and extensible way to handle input and output operations.

### Concepts Covered
- Standard streams (`std::cin`, `std::cout`, `std::cerr`)
- File streams (`std::ifstream`, `std::ofstream`)
- Operator overloading for streams
- Stream state management
- Formatting output

---

## 🔄 Type Casting

C++ provides explicit casting operators to ensure safe and controlled type conversion.

### Concepts Covered
- `static_cast`
- `dynamic_cast`
- `const_cast`
- `reinterpret_cast`
- Safe downcasting in polymorphic hierarchies
- RTTI (Run-Time Type Information)

---

- Effective use of STL containers and algorithms
